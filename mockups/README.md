# Design Direction Mockups

Two full-page hero + opening-flow mockups, each with a toggle for amber accent treatment.
Open each file and click "Hide amber accent" in the top bar to compare both amber states in place.

## A — Engineered Confidence
File: `engineered.html`

The Pentera / Wiz / Vanta register. Inter throughout, sentence case, navy + blue accent,
soft 6–8px radii, generous whitespace, real product-UI mockup in the hero.

Optimized for: feeling parity with the international category leaders. Recognizable as enterprise SaaS at first scroll.

## B — Editorial / Mandiant
File: `editorial.html`

The research-house / Mandiant register. Spectral serif headlines, Inter body, near-monochrome
with one tobacco-amber as editorial accent, hairline rules, drop caps, pull-quotes.

Optimized for: positioning VORNAC as an analyst-grade authority. Differentiation against a sea of identical SaaS sites.

## Amber decision question

Within each mockup, the toggle swaps between:

- **Amber on**: amber used only as a small signal accent (Made-in-Germany badge, editorial highlight). Brand continuity preserved.
- **Amber off**: replaced with neutral charcoal / blue. Cleaner enterprise read, weaker German-engineering signal.
